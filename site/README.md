# 脂硯齋重評石頭記 · 卷子本閱讀器

把全书排成**竖排右起的手卷**：一列一行、列间界栏、天头眉批、行内双行夹批。
每回一卷，卷首有题签（书名 / 卷次 / 回目）。

## 打开

直接双击 `index.html` 即可（纯静态、无需服务器、无需联网）。
若浏览器限制了本地脚本，可在本目录执行任意静态服务器，例如：

```powershell
python -m http.server 8080   # 然后访问 http://localhost:8080
```

## 批语怎么落位

数据源里 4,100 条批语本来就夹在正文的对应位置，解析后按类型分布；**批语开头保留来源标签**（如「甲戌側批：」「庚辰雙行夾批：」）。

| 类型 | 条数 | 排法 |
| --- | ---: | --- |
| 侧批 | 2,060 | 单行小字（半列宽），朱色 |
| 夹批（双行） | 1,442 | 双行小字：每行 2 窄行 × 2 字，朱色 |
| 眉批 | 271 | 天头竖排，自锚点列起**向左**续排（右起），遇重则顺次避让 |
| 回前 / 回末总批 | 217 | 卷首 / 卷末整段 |
| 序（戚蓼生序、甲戌本凡例） | 5 | 与正文同排 |

## 版式参数（`layout.js` 顶部集中定义）

| 项 | 取值 | 说明 |
| --- | --- | --- |
| 正文行距 `rh` | 1.08 × 字号 | 字与字的纵向步进 |
| 列宽 `cw` | 1.45 × 字号 | 含界栏间隙 |
| 批语字号 `sf` | 0.62 × 字号 | 原来偏小，已放大 |
| 批语字距 `sa` | 1.28 × `sf` | 保证字与字之间留空，不再相贴 |
| 天头 `headH` | 版心高的 16% | 眉批区 |
| 正文上下留白 | 1.25 / 0.85 行 | 正文与天头、地脚界线的呼吸空间 |

## 重新生成数据

```powershell
node site/tools/build-data.mjs      # 重解析正文 md
node site/tools/smoke.mjs           # 冒烟测试
```

自检口径：

- **字符守恒**：逐字比对源文与排版结果，80 回全部一致（587,096 正文字 + 范畴批语）；
- **规模**：全书 17,348 列，最长一卷 324 列（第七十八回），全书排版耗时约 60ms。

## 为什么自己做断列，而不是交给浏览器

正文 82% 是汉字、96.7% 是全角字符——**每个字恰好 1em**。因此「第几列、列内第几字」可以纯算术求出，
不必依赖浏览器断行结果再回头测量 DOM。这样带来的好处：

1. 双行夹批的高度恰好是整行，能精确占满列宽、并齐底；
2. 眉批的锚点列号 × 列宽 = x 坐标，天头落点零误差；
3. 列号、断卷、字号切换、批语筛选后的重排，全部是重新计算而不是重新布局；
4. 换字号、换主题不会「跳版」。

代价是要自己处理**禁则**（句读不落列首等），本书以全角标点为主，规则表很小。

## 已知限制（v1）

- **尚未在实机浏览器里验收**：本机沙箱禁止浏览器创建命名管道，无法自动截图，版式参数是用同一套
  算法离线出图核对的。若竖排有偏差，请告诉我具体位置。
- 字体取系统 `SimSun`（正文）/ `KaiTi`（卷首）；未内嵌字体。
- 眉批沿用「向左续排 + 顺次避让」，不做刻本源印中那种手工挪位。
- 校记（17 处「按：」）与 70 个 `□` 缺文暂按普通正文排，未单独成层。
- 移动端只做了基础适配（原生横滑 + 字号收紧）。

## 数据脏点（见 tools/data-report.txt）

- 3 处 `【` 未闭合（872、1371、2910 行）→ 已按「截断到行尾」容错；
- 1 处多余 `】`（1281 行）；
- 2 处「…。该 批：…」嵌套标签 → 已拆成两条批语；
- 1 处重复回目行（702 行）→ 解析时丢弃。
