# 脂砚斋重评石头记 · 卷子本

《脂砚斋重评石头记》八十回全文（UTF-8），外加一个**竖排右起的卷子本阅读器**：
一列一行、列间界栏、天头眉批、行内双行夹批，尽量还原刻本/手卷的读法。

## 在线阅读

<https://charleshahn.github.io/Zhiyanzhai-Shitouji/>

（纯静态页面，也可以直接双击 `site/index.html` 离线打开。）

## 版式要点

| 项 | 做法 |
| --- | --- |
| 竖排 | 自研确定性断列：本书 96.7% 是全角字符，一字一格，列位可算，不依赖浏览器断行 |
| 双行夹批 | 列内分两窄行，朱色小字，随正文流走 |
| 侧批 | 单窄行小字 |
| 眉批 | 天头竖排，自锚点列**向左**续排，遇重避让 |
| 回前 / 回末总批 | 卷首 / 卷末整段 |
| 批语标签 | 保留「甲戌侧批：」「庚辰双行夹批：」等来源标记 |
| 阅读器 | 每回一卷，卷首题签；可切换影印／现代主题、按版本筛选批语、开关列号、调字号 |

## 目录

```
脂砚斋重评石头记.md     全书正文（80 回，UTF-8，无 BOM，LF）
site/
├── index.html          阅读器页面
├── layout.js           排版内核（浏览器与 Node 共用）
├── app.js              渲染与交互
├── style.css           版式与两套主题
├── data/book.js        解析生成的排版数据（约 2.2 MB）
└── tools/
    ├── build-data.mjs  正文 md → data/book.js，并输出脏点清单
    ├── smoke.mjs       无浏览器冒烟测试
    └── preview.mjs     用同一内核算绘制坐标（离线校验）
```

## 重新生成 / 自检

```powershell
node site/tools/build-data.mjs   # 重新解析正文
node site/tools/smoke.mjs        # 冒烟测试
```

自检口径：逐字比对源文与排版结果，80 回全部守恒（587,096 正文字 + 全部批语）；
全书 17,000+ 列，整体排版约 60ms。
